掼蛋小馆 · 联机包

只需房主的一台电脑运行服务。其他人用手机或电脑浏览器加入，不必安装Node。

【同一个 Wi-Fi，最快开玩】
1. 房主电脑先安装 Node.js 22.13 或更新版本：https://nodejs.org/
2. Windows 双击“启动联机.cmd”；Mac/Linux 在此文件夹终端执行：node server.mjs
3. 保持窗口运行。窗口会显示 http://localhost:7788 和手机可用的局域网地址。
4. 房主电脑打开 http://localhost:7788；手机打开窗口显示的 http://192.168.x.x:7788 等地址。
   手机不要填 localhost，它指的是手机自己。所有人连接同一 Wi-Fi；访客网络可能隔离设备。
5. 进入“好友联机”，填昵称并创建房间。把服务地址和8位房间码发给朋友。
6. 朋友填昵称和房间码加入。开局前点空位可换座，正对面一队。2人可同队，也可分两队；空位由AI补齐。
7. 房主开始比赛。每副结束由房主点下一副，继续升级和贡还。房主可随时“一键重开”整桌从2开始。

首次启动若 Windows 防火墙提示，请允许该服务在你使用的专用网络上通信。
找不到 Node：安装后重新打开启动文件。端口被占用：关闭另一份服务，或设置 PORT 环境变量。
不需要 npm install。本包的 server.mjs 已包含规则和AI，只有Node内置依赖。

【异地联机】
将本目录上传到自己有权限的公网服务器或支持长期Node进程的平台，执行 node server.mjs。
平台可用环境变量 PORT 指定端口，服务监听0.0.0.0。将外部HTTPS域名反向代理到该端口。
所有玩家打开同一个HTTPS地址；创建房间后分享地址与房间码。
也可使用本目录 Dockerfile 构建容器（默认端口7788，单实例）。
没有附带已部署的公共服务器，也不需要在HTML中填任何API密钥。
第一次部署推荐查看同目录“异地联机上手.txt”，按 Render＋GitHub 的页面操作逐步完成；render.yaml 已准备好。

【联机机制】
服务只给每名玩家发送其自己的手牌；出牌、升级、进贡和还贡都由服务验证。
在线思考不限时，方便学习。断线25秒后AI接管，恢复原凭证可回到原座位。
显式离开释放座位；开局后暂不能加入，等本副结束再加入。房主断线可由其他在线玩家接任。
刷新页面一般保留凭证；换浏览器或清理数据后，原凭证无法恢复。
如果同一台电脑要扮演多人测试，请用不同浏览器或独立的无痕会话，避免共享同一座位凭证。
无人访问15分钟的房间会回收。服务重启会清空所有联机房间；本版用内存保存房间，不支持多服务实例共享。
保持服务运行。关闭终端或按Ctrl+C即停止服务。
